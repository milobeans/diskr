A fast disk usage explorer for the macOS terminal

diskr shows folder sizes by actual disk allocation, finds caches and build output to review for cleanup, and tracks what changed between scans. It was built as a simpler alternative to Finder and the macOS storage settings, which make it hard to see what is actually using your disk.

Your first scan

After installing, run diskr ~/Downloads to start with a familiar folder.

  1. Measure. S sizes visible folders. . includes hidden ones.
  2. Inspect. Select a folder and press t for its largest files, or ⏎ to open it.
  3. Choose. i shows details and f reveals an item in Finder. Review before moving anything to the Trash.

? shows every key, g opens folders and saved profiles, and q quits. If the scan reports limited access, see what it means and how to refresh it.

Features

The file browser scans lazily around your selection using getattrlistbulk(2). Cached sizes are revalidated with FSEvents when reliable replay is available.

Sizes by allocated space

Folders sort by the bytes they occupy on disk. Apparent size is shown when it differs, as with APFS clones and sparse files.

S · .

Cleanup suggestions

Caches, build output and package stores, each labeled safe, regenerable or risky with a reason. Reports never delete anything.

diskr --reclaim ~

Change tracking

Growth badges compare each folder with its session baseline. Save baselines and compare them later.

B · diskr --diff ~

APFS space report

Container free space, local snapshots and what is actually available, side by side.

diskr --space ~

Packages and projects

Homebrew, Cargo, npm, pip and Bun packages, plus project dependency folders, with sizes. Dependency leaves may still be used by you or your scripts.

p · diskr --packages ~

Scriptable reports

Every report has JSON output with a versioned schema. --strict exits with status 2 when data is incomplete.

--json · --strict

Install

For macOS 15 or newer, on Apple Silicon and Intel. Homebrew and native archives need no Rust toolchain.

If you use Homebrew, install from the tap maintained in this repository:

brew tap milobeans/diskr https://github.com/milobeans/diskr
brew install milobeans/diskr/diskr

Homebrew selects the native archive for your Mac and verifies its checksum. Run diskr ~/Downloads to begin. To update later, run brew update followed by brew upgrade milobeans/diskr/diskr.

Requires Rust 1.88 or newer.

cargo install diskr --locked

Run diskr to browse your home folder, or diskr ~/Downloads to start elsewhere.

In a new, empty directory, download and verify the installer from the latest release:

curl --fail --location --remote-name https://github.com/milobeans/diskr/releases/latest/download/install-diskr.sh
curl --fail --location --remote-name https://github.com/milobeans/diskr/releases/latest/download/SHA256SUMS
checksum=$(awk '$2 == "install-diskr.sh" { print }' SHA256SUMS)
test -n "$checksum" && printf '%s\n' "$checksum" | shasum -a 256 -c -

Only after the checksum reports OK, run it. The installer selects your architecture and verifies the matching release archive:

sh install-diskr.sh

Start a scan directly:

"$HOME/.local/bin/diskr" ~/Downloads

The default location is ~/.local/bin. See PATH setup and a custom install location to run diskr by name. The installer does not edit your shell settings.

Check each release's notes and, when provided, distribution.json for its signing status. Signed releases include notarized, stapled DMGs. Version 0.1.83 archives are unsigned and not notarized; macOS or organization policy may require another installation route.

git clone https://github.com/milobeans/diskr
cd diskr
cargo install --path . --locked
