A fast disk usage explorer for the macOS terminal

diskr shows folder sizes by actual disk allocation, finds caches and build output you can safely remove, and tracks what changed between scans.

Features

Scanning uses getattrlistbulk(2) and only covers what you are looking at. Sizes are cached between runs and revalidated with FSEvents.

Sizes by allocated space

Folders sort by the bytes they occupy on disk. Apparent size is shown when it differs, as with APFS clones and sparse files.

S · .

Cleanup suggestions

Caches, build output and package stores, each labeled safe, regenerable or risky with a reason. Reports never delete anything.

diskr --reclaim ~

Change tracking

Folders that changed since their last scan show a growth badge. Save baselines and compare them later.

B · diskr --diff ~

APFS space report

Container free space, local snapshots and what is actually available, side by side.

diskr --space ~

Packages and projects

Homebrew, Cargo, npm, pip and Bun packages, plus project dependency folders, with sizes.

p · diskr --packages ~

Scriptable reports

Every report has JSON output with a versioned schema. --strict exits with status 2 when data is incomplete.

--json · --strict

Install

macOS on Apple Silicon or Intel. Prebuilt archives require macOS 15 or newer.

Requires Rust 1.88 or newer.

cargo install diskr

Run diskr to browse your home folder, or diskr ~/Downloads to start elsewhere.

Download the archive for your Mac and verify its checksum from GitHub Releases. Run this in a new, empty directory:

case "$(uname -m)" in
  arm64) target=aarch64-apple-darwin ;;
  x86_64) target=x86_64-apple-darwin ;;
  *) echo "Unsupported architecture" >&2; exit 1 ;;
esac
archive="diskr-$target.tar.gz"
curl --fail --location --remote-name "https://github.com/milobeans/diskr/releases/latest/download/$archive"
curl --fail --location --remote-name "https://github.com/milobeans/diskr/releases/latest/download/SHA256SUMS"
checksum=$(awk -v archive="$archive" '$2 == archive { print }' SHA256SUMS)
test -n "$checksum" && printf '%s\n' "$checksum" | shasum -a 256 -c -

After the checksum verifies, install it:

tar -xzf "$archive"
mkdir -p "$HOME/.local/bin"
install -m 755 diskr "$HOME/.local/bin/diskr"
"$HOME/.local/bin/diskr" --help

Archives are not Developer ID signed or notarized; organization policy may require a different route. No quarantine bypass is needed or recommended.

git clone https://github.com/milobeans/diskr
cd diskr
cargo install --path .
